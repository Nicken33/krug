# «Круг» (TipoDS) — Discord-подобный голосовой и текстовый мессенджер для друзей

**«Круг»** — это полностью бесплатное, self-hosted решение для голосового общения, текстовых чатов и стриминга экрана с друзьями без подписок, привязки карт и SMS.

---

## 🚀 Способы запуска

### 1. Запуск десктопного приложения Windows
Дважды кликните по файлу:
```bat
Запуск-Приложения.bat
```
Откроется нативное Windows-окно с тёмной темой в стиле Discord, поддержкой захвата экрана игр/приложений и глобальной рацией (Push-to-Talk).

### 2. Сборка готового автономного `.exe` (Portable)
Дважды кликните по файлу:
```bat
Собрать-EXE.bat
```
В папке `dist-electron/` появится готовый файл `Krug-Portable-1.0.0.exe`, который можно скинуть друзьям на флешке или через облако.

### 3. Подключение друзей через интернет (HTTPS-туннель)
Если друзья заходят с обычного браузера (без установки приложения) или вы находитесь за домашним роутером (NAT / CGNAT):
Дважды кликните по файлу:
```bat
Поделиться-с-друзьями.bat
```
Скрипт автоматически поднимет защищенный HTTPS-туннель и выдаст прямую ссылку вида `https://xxxx.trycloudflare.com/?room=krug-main`. Друзья смогут зайти по ссылке в один клик с любого браузера (Chrome, Edge, Firefox, мобильные устройства) — микрофон и стрим экрана будут работать без ограничений.

---

## 🛠 Ключевой функционал

- **Голосовые каналы (WebRTC):** Быстрая голосовая связь с мгновенной индикацией говорящего (VAD) и зеленой подсветкой аватаров (<20мс).
- **Стриминг экрана (Screen Sharing):** Решена проблема «чёрного экрана» благодаря нативным селекторам окон (`desktopCapturer`) и корректной инициализации WebRTC-видеопотока. Поддерживается 60 FPS и захват аудио.
- **Push-to-Talk (Рация):** Глобальный хоткей в играх и программах на Windows.
- **Текстовые каналы и личные сообщения:** Мгновенный обмен сообщениями через WebSockets с сохранением истории переписки.
- **Мониторинг сети:** Отображение реального пинга (RTT в миллисекундах) и состояния WebRTC ICE-соединения.
- **Управление звуком:** Mute микрофона, Deafen (заглушить звук) в один клик.

## 📁 Структура проекта

- `electron/` — Нативный движок Windows-приложения (окна, системные хоткеи, захват экранов/окон).
- `client/` — Реактивный интерфейс (React + Vite + TailwindCSS + Lucide Icons).
- `server/` — WebSocket сигнальный сервер комнат и истории сообщений (Express + Socket.io).
- `scripts/` — Утилиты запуска туннеля и уведомлений Windows.
- `dist-electron/` — Папка со скомпилированным Windows `.exe`.
